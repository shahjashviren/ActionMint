# Assets

The home illustration is built from CSS; the supplied ActionMint mark is a local, opaque PNG with a fixed midnight background, so its treatment does not change with the UI theme. It is used in the header/footer, Supabase Auth screen, and browser tab icon.

| Asset | File | Notes |
|---|---|---|
| ActionMint mark | `frontend/public/assets/actionmint-mark.png` | User-supplied target/check mark on a fixed dark background; used consistently across the app and as the favicon |
| Meeting recap card | generated by `frontend/src/pages/MeetingPage.tsx` | Deterministic, local SVG based on reviewed meeting data |
| Category transition art | optional paths in `frontend/public/assets/categories/` | When no category frame PNGs are installed, the transition uses an accessible inline geometric fallback glyph. |
