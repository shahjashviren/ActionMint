# ActionMint walkthrough

1. Sign in or create an account with Supabase email/password Auth.
2. Start a workspace by pasting a transcript, choosing an audio/video recording, or entering a public YouTube URL.
3. Let Gemini prepare a draft of the summary, decisions, action items, risks, and follow-ups.
4. Review evidence links, correct uncertain details, and edit the result.
5. Export the reviewed notes as Markdown, JSON, CSV, or calendar events. Meeting content is temporary; it is not stored as Supabase meeting history.
6. For the visible meeting-link experience, select **Join a meeting**, enter a valid Meet/Zoom/Teams URL, and submit. ActionMint displays a courteous **Coming soon** notice and does not join the call or make a bot request.

Provider rate limits, availability, and third-party processing terms apply. Never present the meeting-link placeholder as live recording.
