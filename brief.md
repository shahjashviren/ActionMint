# ActionMint — product brief

- **Name:** ActionMint
- **Pitch:** Turn meeting transcripts, recordings, and public YouTube videos into evidence-linked decisions and follow-up actions that people can review, edit, and export.
- **Audience:** Student project teams, clubs, small product teams, and anyone responsible for meeting follow-through.
- **Authentication:** Supabase email/password Auth only.
- **Meeting content:** Temporary server memory/files and active browser session only; no Supabase meeting tables, storage, or server-side history.
- **AI:** Gemini API for transcript analysis, audio transcription, and supported public YouTube processing.
- **Meeting links:** Visible Meet/Zoom/Teams input; submitting a valid URL displays a friendly Coming Soon popup. No joining, bot request, or simulated result.
- **Exports:** Markdown, JSON, CSV, and calendar events.
- **Aesthetic:** An editorial meeting notebook with layered gradients. Light mode uses warm cream with terracotta, lilac, and sea-glass ambience; dark mode uses deep ink with teal, indigo, and muted amber glows. Chartreuse remains a small, purposeful accent.
- **Palette:** Light base `#F4EFE4`; dark base `#11151D`; raised surfaces `#FCF9F1` / `#191F29`; text `#252A2C` / `#F3F1EC`; chartreuse `#C7F36D`; terracotta `#F29A70`; periwinkle `#6875DC`; sea glass `#41BAB2`.
- **Typography:** Space Grotesk for display and DM Sans for interface/body copy (self-hosted frontend dependencies via pnpm).

## Home copy
1. Hero: “The meeting ends. The momentum doesn’t.” Supporting copy: decisions and tasks with evidence, owners, and dates kept honest.
2. Understand: “Start with the real conversation.”
3. Verify: “Keep uncertainty visible.”
4. Follow through: “Make the notes yours.”
5. CTA: “Bring the conversation. Leave with a plan.”
